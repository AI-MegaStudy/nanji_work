# Nanji Hourly Enriched V2

이 폴더는 기존 `nanji_hourly_estimated` 데이터를 바탕으로 외부 데이터를 실제로 결합한 2차 결과물입니다.

## 포함 파일

- `nanji_hourly_enriched_2020.csv` ~ `nanji_hourly_enriched_2026.csv`
  - 기존 시간별 추정 데이터에 `문화행사 일별 피처`를 결합한 연도별 파일
- `nanji_future_hourly_adjusted_20260403_20260407.csv`
  - 기상청 단기예보를 사용해 2026-04-03 ~ 2026-04-07 구간을 예측용으로 보정한 파일

## 실제로 결합한 데이터

- 문화행사 정보: 마포구 및 난지/상암/월드컵/하늘공원 관련 장소
- 기상청 단기예보: 2026-04-03 ~ 2026-04-07
- 도로 소통: 교통 스냅샷 1건을 미래 보정 파일에 참고용으로 반영했습니다.

## 해석 주의

- 연도별 enriched 파일은 `기존 시간별 추정값 + 행사 피처` 중심입니다.
- 미래 보정 파일은 실측 주차대수가 없는 구간에 대해 `과거 유사 요일/월 평균 + 날씨/행사/교통 보정`을 적용한 결과입니다.
