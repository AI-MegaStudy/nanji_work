# Nanji Hourly Estimated Dataset

이 폴더의 CSV는 난지 주차장의 `실측 시간별 데이터`가 아니라, 일별 주차대수와 이용시간을 바탕으로 생성한 `시간별 추정 데이터`입니다.

## 생성 범위

- 시작일: 2020-02-11
- 종료일: 2026-04-02
- 생성 단위: 1시간
- 연도별 파일 분리: 2020 ~ 2026

## 사용한 원본 데이터

- 일별 주차 데이터: `/Users/electrozone/Documents/GitHub/nanji_work/hmw/Data/한강공원 주차장 일별 이용 현황.csv`

## 추정 방식

1. 난지 관련 주차장 데이터를 날짜별로 합산
2. 일별 총 주차대수를 기준으로 24시간 분배 비율 생성
3. 분배 비율은 평일/주말과 계절에 따라 다르게 적용
4. 일별 이용시간 / 주차대수로 평균 체류시간을 계산
5. 평균 체류시간을 이용해 시간별 활성 차량 수(`estimated_active_cars`)를 추정

## 주요 컬럼

- `estimated_entries`: 해당 시간에 들어온 차량의 추정값
- `estimated_active_cars`: 해당 시간에 주차장에 머물러 있는 차량 수의 추정값
- `estimated_active_cars_change`: 이전 시간 대비 활성 차량 수 변화량 추정값

## 주의사항

- 이 데이터는 관측 로그가 아니라 추정치입니다.
- 실제 입차/출차 시간 로그가 아니므로, 시간별 정답 데이터로 쓰기보다 패턴 분석과 초기 모델링용으로 사용하는 것이 적절합니다.
