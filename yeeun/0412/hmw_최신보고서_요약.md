# HMW 최신 보고서 요약

- 기준 문서: `hmw/Note/nanji_weighted_ridge_modeling_report.md`
- 기준 시점: 폴더 내 최근 수정 파일 기준 2026-04-11
- 주제: 난지 한강공원 시간별 주차 수요(`estimated_active_cars`) 예측 모델 정리

## 1. 보고서 목적

이 보고서는 난지 한강공원의 시간대별 주차 수요를 예측하기 위한 모델링 과정을 정리한 문서다.  
직접 측정한 시간별 주차 로그가 아니라, 일별 주차 원본 데이터를 24시간 단위로 확장해 만든 추정형 데이터셋을 사용했다.

핵심 목표는 다음과 같다.

- 시간대별 추정 주차 차량 수 예측
- 이후 이를 `여유 주차공간 수`로 변환해 운영에 활용할 수 있도록 구조화
- 해석이 쉬우면서도 운영에 연결 가능한 모델 선정

## 2. 데이터와 전처리 핵심

- 분석 대상 변수: `estimated_active_cars`
- 데이터 기간: `2022-01-01` ~ `2025-12-31`
- 전체 행 수: `34,920`
- 결측 타깃: `0`
- 중복 행: `0`

운영시간은 `06:00~23:00`로 간주했고, `00:00~05:00` 구간은 운영시간 외로 보고 값을 `0`으로 유지했다.

학습 구간은 시계열 순서를 유지해 아래처럼 분리했다.

- `train`: 2022년~2023년
- `valid`: 2024년
- `test`: 2025년

추가 점검 내용은 다음과 같다.

- 입력 변수 분포 확인
- 로그 변환 필요 후보 검토
- 타깃 이상값/특이값 구분
- 입력 변수 이상값 점검

전처리 결과상 타깃 `estimated_active_cars`는 상한선을 넘는 값이 있었지만 모두 연속적인 높은 수요 흐름으로 판단되어 제거하지 않았다.  
입력 변수 쪽에서는 자전거 이용시간/이동거리 관련 변수에서만 실제 제거가 필요한 값이 발견되어 총 `8개` 행을 제거했다.

## 3. 모델링 방식

보고서의 모델 구조는 한 번에 모든 것을 맞추는 방식이 아니라, 패턴을 먼저 설명하고 남는 오차를 보정하는 구조다.

흐름은 아래와 같다.

1. `day_type x hour` 평균으로 시간대 기본 패턴 생성
2. 이를 회귀식 형태의 `base_value`로 정리
3. 월별 차이를 `month_weight`로 보정
4. 시간대 차이를 `hour_weight`로 보정
5. 외부 변수와 함께 Ridge 회귀 적용

즉 구조적으로는 `기본 회귀식 + month_weight + hour_weight + Ridge` 조합이다.

또한 `hour_sin`, `hour_cos`, `month_sin`, `month_cos`를 사용해 시간과 계절의 주기성을 반영했다.

## 4. 주요 성능 비교

보고서에서 제시한 `test` 기준 주요 성능은 아래와 같다.

| 모델 | RMSE | MAE | R² |
|:--|--:|--:|--:|
| `weighted_core` | 59.6065 | 30.0520 | 0.7254 |
| `weighted_extended` | 56.5583 | 28.0493 | 0.7527 |
| `weather_only_extended` | 55.1974 | 28.0221 | 0.7645 |

성능만 보면 `weather_only_extended`가 가장 좋았고, 운영 가능성까지 고려했을 때도 가장 적절한 방향으로 평가됐다.

## 5. 최종 운영형 모델

보고서는 미래 시점에서도 실제로 확보 가능한 입력을 중요하게 봤다.

- 교통, 자전거, 행사 변수는 과거 설명력은 있지만 미래 실시간 확보가 어려움
- 날씨는 예보 데이터를 활용할 수 있어 운영 연결성이 높음

그래서 최종적으로는 날씨 기반 운영형 모델을 단순화한 `weather_only_extended_final`을 채택했다.

최종 운영형 모델의 `test` 성능:

- RMSE: `55.0747`
- MAE: `27.9298`
- R²: `0.7655`

최종 사용 feature는 총 `13개`다.

- `pattern_prior`
- `month_weight`
- `hour_weight`
- `day_type_offday`
- `hour_sin`
- `hour_cos`
- `month_sin`
- `month_cos`
- `is_holiday`
- `temperature_2m`
- `relative_humidity_2m`
- `weather_code`
- `wind_gusts_10m`

## 6. 해석 포인트와 한계

보고서의 핵심 해석은 다음과 같다.

- 일반적인 운영 시간대 수요 예측에는 현재 모델이 충분히 실용적임
- 시간대/계절 패턴 보정값이 모델의 큰 뼈대를 잡음
- 눈, 공휴일, 날씨 같은 외부 조건이 추가 설명력을 제공함

다만 한계도 분명하게 제시했다.

- 실제값 `500 이상`의 고혼잡 구간에서는 과소예측 경향이 있음
- 오차가 큰 시간대는 주로 `12~19시`, 특히 `13~16시`
- 어려운 시기는 `4~6월`, `9~10월`
- 주말/휴일 성격이 강한 날에서 오차가 더 커짐

즉 평시 운영 예측에는 유용하지만, 매우 혼잡한 피크 시간대는 보수적으로 해석해야 한다는 결론이다.

## 7. 실무 적용 방식

현재 모델이 직접 예측하는 값은 `estimated_active_cars`이며, 이를 여유 주차공간 수로 바꾸려면 총 주차면 수가 추가로 필요하다.

계산 방식:

- `predicted_occupied_cars = predicted_estimated_active_cars`
- `available_spaces = max(total_capacity - predicted_occupied_cars, 0)`

즉 최종 운영 방향은 아래와 같다.

1. 시간/월 패턴 변수 생성
2. 핵심 날씨 예보 변수 결합
3. Ridge 모델로 점유 차량 수 예측
4. 총 주차면 수와 비교해 여유 주차공간 수로 변환

## 8. 한줄 결론

HMW의 최신 보고서는 난지 한강공원 주차 수요를 설명 가능한 선형 구조로 예측하는 작업이며, 실제 운영용 최종안으로는 날씨 예보 기반 `13개 feature`의 Ridge 모델을 선택했고, 일반 구간 예측에는 실용적이지만 `500 이상` 고혼잡 구간은 과소예측 가능성을 함께 관리해야 한다고 정리했다.
