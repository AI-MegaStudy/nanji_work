# Nanji Work — 난지한강공원 주차 데이터 분석

AI-MegaStudy 팀의 난지한강공원 주차 혼잡도 예측 프로젝트에서 데이터 분석과 실험 작업을 정리하는 저장소입니다.

## 프로젝트 개요
주차 관련 데이터를 살펴보고 혼잡도 예측 서비스에 활용할 수 있는 분석 결과와 실험 코드를 관리합니다. 구체적인 데이터 처리 방식은 저장소의 코드와 노트북을 참고해 주세요.

## 관련 저장소
- [nanji_app](https://github.com/AI-MegaStudy/nanji_app) — 앱
- [nanji_web](https://github.com/AI-MegaStudy/nanji_web) — 웹 대시보드

## 실행 안내
필요한 데이터 파일과 패키지 버전을 먼저 확인하세요. 접근 권한이 필요한 데이터나 개인 정보는 공개 저장소에 업로드하지 마세요.
