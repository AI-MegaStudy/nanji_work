# Open-Meteo 난지 연도별 CSV 설명

대상 폴더:
- `ose/Data`

대상 파일:
- `open_meteo_nanji_2020.csv`
- `open_meteo_nanji_2021.csv`
- `open_meteo_nanji_2022.csv`
- `open_meteo_nanji_2023.csv`
- `open_meteo_nanji_2024.csv`
- `open_meteo_nanji_2025.csv`
- `open_meteo_nanji_2026.csv`

## 1. 데이터 개요

- 데이터 출처: Open-Meteo Archive API
- 대상 지점: 난지 한강공원 인근 좌표
- 좌표: 위도 `37.5686`, 경도 `126.8789`
- 시간대: `Asia/Seoul`
- 단위: 1시간
- 파일 구성: 연도별 CSV 1개

각 CSV는 해당 연도의 시간별 날씨 데이터를 담고 있습니다.

- `2020` ~ `2025`: 해당 연도 전체
- `2026`: `2026-01-01`부터 `2026-04-06`까지 저장

## 2. 파일명 규칙

- 형식: `open_meteo_nanji_YYYY.csv`
- 예시: `open_meteo_nanji_2024.csv`

## 3. 기본 컬럼

### `datetime`
- 의미: 시간별 관측 기준 시각
- 형식: `YYYY-MM-DDTHH:MM`
- 예시: `2026-01-01T00:00`

### `date`
- 의미: 날짜 부분만 분리한 값
- 형식: `YYYY-MM-DD`

### `hour`
- 의미: 시간대
- 범위: `0 ~ 23`

### `year`
- 의미: 연도

### `month`
- 의미: 월
- 범위: `1 ~ 12`

### `day`
- 의미: 일
- 범위: `1 ~ 31`

### `weather_code_label`
- 의미: `weather_code`를 사람이 읽기 쉬운 한글 상태로 변환한 값
- 예시: `맑음`, `흐림`, `약한 비`, `뇌우`
- 설명: 숫자 코드 해석 없이 바로 상태를 파악할 수 있도록 추가한 보조 컬럼

## 4. 기온 / 습도 관련 컬럼

### `temperature_2m`
- 의미: 지상 2m 기온
- 단위: `°C`

### `relative_humidity_2m`
- 의미: 지상 2m 상대습도
- 단위: `%`

### `dew_point_2m`
- 의미: 지상 2m 이슬점 온도
- 단위: `°C`

### `apparent_temperature`
- 의미: 체감온도
- 단위: `°C`

## 5. 강수 / 적설 관련 컬럼

### `precipitation`
- 의미: 시간당 총 강수량
- 단위: `mm`

### `rain`
- 의미: 시간당 비 형태 강수량
- 단위: `mm`

### `snowfall`
- 의미: 시간당 적설량
- 단위: `cm`

### `snow_depth`
- 의미: 적설 깊이
- 단위: `m`

## 6. 날씨 상태 / 기압 / 구름 관련 컬럼

### `weather_code`
- 의미: Open-Meteo 날씨 코드
- 설명: 맑음, 흐림, 비, 눈 등의 상태를 숫자 코드로 표현한 값

주요 코드 예시는 다음과 같습니다.

- `0`: 맑음
- `1`: 대체로 맑음
- `2`: 부분적으로 흐림
- `3`: 흐림
- `45`: 안개
- `48`: 착빙 안개
- `51`, `53`, `55`: 약함/보통/강한 이슬비
- `61`, `63`, `65`: 약함/보통/강한 비
- `71`, `73`, `75`: 약함/보통/강한 눈
- `80`, `81`, `82`: 약함/보통/강한 소나기
- `95`: 뇌우
- `96`, `99`: 우박 동반 뇌우

### `pressure_msl`
- 의미: 평균 해면기압
- 단위: `hPa`

### `surface_pressure`
- 의미: 지면 기압
- 단위: `hPa`

### `cloud_cover`
- 의미: 전체 운량
- 단위: `%`

### `cloud_cover_low`
- 의미: 저층운 운량
- 단위: `%`

### `cloud_cover_mid`
- 의미: 중층운 운량
- 단위: `%`

### `cloud_cover_high`
- 의미: 상층운 운량
- 단위: `%`

## 7. 시정 / 바람 관련 컬럼

### `visibility`
- 의미: 시정 거리
- 단위: `m`
- 설명: 일부 시각에는 결측일 수 있음

### `wind_speed_10m`
- 의미: 지상 10m 풍속
- 단위: `km/h`

### `wind_direction_10m`
- 의미: 지상 10m 풍향
- 단위: `°`
- 설명: 북쪽이 `0`, 동쪽이 `90`, 남쪽이 `180`, 서쪽이 `270`

### `wind_gusts_10m`
- 의미: 지상 10m 순간최대풍속
- 단위: `km/h`

## 8. 일사량 관련 컬럼

### `shortwave_radiation`
- 의미: 단파복사량
- 단위: `W/m2`

### `direct_radiation`
- 의미: 직달일사량
- 단위: `W/m2`

### `diffuse_radiation`
- 의미: 산란일사량
- 단위: `W/m2`

### `sunshine_duration`
- 의미: 해당 시간 동안의 일조 지속시간
- 단위: `초`

## 9. 해석 시 주의할 점

- 이 데이터는 Open-Meteo의 재분석 또는 아카이브 기반 시간별 날씨 데이터입니다.
- 실제 난지 주차장 현장 계측값이 아니라, 해당 좌표 기준의 격자형 날씨 데이터입니다.
- `visibility`처럼 일부 컬럼은 특정 시각에 비어 있을 수 있습니다.
- `weather_code`는 숫자 코드이므로, 사람이 읽기 쉬운 상태값이 필요하면 별도 매핑 테이블을 추가해 해석하는 것이 좋습니다.
- 이번 CSV에는 이 해석용 컬럼으로 `weather_code_label`이 함께 포함되어 있습니다.

## 10. 모델링 활용 예시

- 시간별 주차 수요 예측 모델의 외생 변수
- 강수, 기온, 풍속에 따른 공원 방문 수요 변화 분석
- 계절성, 야외 활동성, 악천후 영향 분석
- 기존 `nanji_hourly_model_dataset_2020_2026.csv`와 `datetime` 기준 병합
